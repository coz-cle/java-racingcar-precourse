# 구현 기능 목록

### 1. 자동차 경주 준비
- 자동차명 입력 및 저장
  - [x] "경주할 자동차 이름을 입력하세요. 자동차 이름은 쉼표를 기준으로 구분하여 입력해주세요." 출력하기
  - [x] 경주할 자동차명 입력받기
    - [x] [예외] 입력으로 문자, 숫자, 쉼표가 아닌 값이 입력된 경우 예외 발생시키기
  - [x] 경주할 자동차 목록 저장하기
    - [x] [예외] 자동차 이름 길이가 0인 경우 예외 발생시키기
    - [x] [예외] 자동차 이름이 공백인 경우 예외 발생시키기
    - [x] [예외] 자동차 이름 길이가 5자를 초과한 경우 예외 발생시키기
    - [x] [예외] 이미 존재하는 자동차 이름일 경우 예외 발생시키기
- 경주 시도횟수 입력 및 저장
  - [x] "경주를 시도할 횟수를 입력해수제요." 출력하기
  - [x] 경주 시도 횟수 입력받기
    - [x] [예외] 입력으로 숫자가 아닌 값이 입력된 경우 예외 발생시키기
    - [x] [예외] 입력으로 1 이상의 정수가 아닌 값이 입력된 경우 예외 발생시키기
  - [x] 경주 시도횟수(정수) 저장하기

### 2. 자동차 경주 시작
- [x] 모든 자동차의 전진상태 출력하기
- [x] 자동차 움직이기 
  - [x] 0에서 9 사이의 난수를 제공하는 난수 생성기(Random) 개발하기
  - [x] 난수 생성기를 통한 값이 4 이상일 경우 자동차를 전진시키고, 3 이하일 경우 자동차 멈추기
- [x] 경주 종료 후 자동차의 총 전진상태 출력하기

### 3. 자동차 경주 결과 출력
- [ ] 경주 종료 후 전진 수가 가장 큰 자동차를 우승자 자동차 목록으로 저장하기
- [ ] 우승한 자동차 목록 출력하기("최종 우승자 : " 문자열 뒤에 우승한 자동차 목록 출력)
